---

### Bước 1: Cài đặt WSL và Ubuntu (Thực hiện trên PowerShell của Windows)

1. Ngài mở **PowerShell** với quyền **Administrator** (Chạy dưới quyền quản trị viên).
2. Chạy lệnh cài đặt Ubuntu cho WSL:


```powershell
wsl --install -d Ubuntu

```


3. Sau khi cài xong, hệ thống sẽ yêu cầu ngài nhập **Username** và **Password** cho Linux (lúc gõ mật khẩu sẽ không hiện ký tự lên màn hình, ngài cứ gõ xong rồi bấm `Enter`).

---

### Bước 2: Vào WSL và cài đặt Docker Engine (Thực hiện bên trong Ubuntu)

Ngài gõ lệnh vào WSL (nếu chưa vào):

```powershell
wsl

```

Sau khi màn hình chuyển sang giao diện Linux (hiện tên user của ngài), ngài copy và dán lần lượt các khối lệnh sau:

**1. Cập nhật hệ thống và cài các gói hỗ trợ:**

```bash
sudo apt-get update
sudo apt-get install ca-certificates curl

```

**2. Thêm khóa GPG và kho lưu trữ (Repository) của Docker:**

```bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update

```

**3. Cài đặt Docker Engine và Docker Compose:**

```bash
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

```

**4. Khởi động dịch vụ Docker và cấp quyền cho User:**

```bash
sudo service docker start
sudo usermod -aG docker $USER

```

### Bước 3: Kiểm tra thành quả

1. Ngài đóng hẳn cửa sổ terminal hiện tại lại, mở một cửa sổ **PowerShell** mới trên Windows rồi gõ:


```powershell
wsl

```


2. Chạy lệnh kiểm tra Docker:


```bash
docker run hello-world

```



Nếu màn hình hiện dòng chữ **"Hello from Docker!"** là ngài đã hoàn tất 100 việc cài đặt Docker Engine trên WSL mà không cần dùng đến Docker Desktop rồi ạ!


Dạ thưa ngài, em xin giải đáp từng ý để ngài nắm rõ cách vận hành hằng ngày ạ:

### 1. Mỗi khi mở máy tính, ngài có cần mở Docker gì không?

* **Không cần mở gì cả** nếu lúc trước ngài đã cấu hình bật `systemd` cho WSL. Khi ngài mở terminal và gõ lệnh `wsl`, dịch vụ Docker sẽ tự động chạy ngầm.
* Tuy nhiên, nếu lâu lâu ngài gõ lệnh mà thấy báo lỗi kết nối socket (do WSL bị tắt hẳn), ngài chỉ cần chạy một lệnh cực kỳ nhanh bên trong WSL để khởi động lại dịch vụ Docker:
```bash
sudo service docker start

```



---

### 2. Khi start dự án, chỉ cần chạy Docker Compose thôi đúng không?

* **Đúng vậy thưa ngài!** Khi dự án của ngài đã có sẵn file `docker-compose.yml`, ngài chỉ cần trỏ thư mục đến dự án đó và chạy lệnh:
```bash
docker compose up -d

```


* Lệnh này sẽ tự động build, kéo các image cần thiết và khởi chạy toàn bộ các container (như web, database, redis,...) ở chế độ chạy ngầm (`-d`) một cách cực kỳ gọn gàng và nhanh chóng ạ.
